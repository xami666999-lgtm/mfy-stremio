# MFY Stremio addon

Catalogs for movies, shows, and anime, plus the same embed players MFY uses.

## Install
Once hosted, add this in Stremio:

```
https://YOUR-HOST/manifest.json
```

## Run
```
npm install
npm start
```

Then open `http://localhost:7000/manifest.json`.

## What it serves
- Trending and popular movies
- Trending and popular shows
- Anime catalog
- Search
- Streams that open the MFY embed players (vidsrc, vidlink, vidcore)
